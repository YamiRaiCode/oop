# 3x+1 Algorithm in PHP

<p>This project demonstrates the <strong>Collatz Conjecture</strong>, also known as the <i>3x + 1</i> problem, written in PHP.</p>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li>PHP</li>
  <li>XAMPP (Localhost)</li>
  <li>Git / GitHub</li>
</ul>

<h2>📁 Project Files</h2>
<ul>
  <li><code>3x+1.php</code>: Main file containing the algorithm</li>
</ul>

<h2>🚀 How to Run</h2>
<ol>
  <li>Clone this repository</li>
  <li>Place files inside <code>htdocs</code> if using XAMPP</li>
  <li>Access via <code>localhost/OOP/3x+1.php</code></li>
</ol>
